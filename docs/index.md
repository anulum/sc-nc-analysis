# SC-NC Analysis

SC-NC Analysis is being built as the analysis layer split out of SC-NeuroCore: the observable series taken from runs and recordings, their statistical summaries, and the fits, cohorts and measurements that compare models with data. It imports SC-NC Core, SC-NC Catalogue and SC-NC Engine. Its current executable surface is repository validation tooling. It has no installed analysis package, statistics runner, model fitter or qualified record schema.

Read [Architecture](ARCHITECTURE.md), [validation tooling](validation-tooling.md), [data boundaries](THREAT_MODEL.md) and the [repository boundary decision](adr/0001-repository-boundary.md).
